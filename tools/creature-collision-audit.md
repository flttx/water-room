# 怪物碰撞修复记录

状态：此前复现的问题已修复，以下回归检查通过。

## 修复内容

| 对象 | 原问题 | 修复方式 |
| --- | --- | --- |
| 最终命中判定 | 巨型触手怪、鲸鱼、蜘蛛蟹、鮟鱇鱼、潜伏鱼可以隔柱抓获 | 在实际攻击接触点重新检查墙体、地面和栈道遮挡；水母蜇伤也增加遮挡检查 |
| 蜘蛛蟹 | 长腿穿柱、穿栈道 | 按真实蒙皮检查身体和各条腿；拒绝穿柱落脚点，调整落脚位置，受阻时后退重新选路 |
| 巨型触手怪 | 身体升起时穿平台，触手穿柱 | 调整上浮位置并限制完整姿态；触手检查半径和节点间连线，逐段收回受阻部分，限制修正速度并保持根部连接 |
| 潜伏鱼 | 部分出生点嵌墙，尾巴及触须穿墙 | 根据头部和附肢根部体积寻找安全出生位置；约束转身、扑击和完整触须跨度 |
| 鲸鱼 | 腹部和尾部入底、转身穿柱 | 提高巡游深度下限，按真实蒙皮限制运动和骨骼姿态；推挤玩家时检查地形；复活保留安全姿态 |
| 水母 | 触须穿进深浅水交界的台阶 | 使用各触须点所在位置的地面高度，并检查触须及连接线的完整跨度；伞体增加体积检查 |
| 鮟鱇鱼 | 出生时埋进池底，扑击缺少全身约束 | 提高静止位置，按实际骨骼蒙皮限制扑击姿态 |
| 深渊巨兽 | 上部鳍擦过深渊侧墙下缘 | 按真实模型上部轮廓降低巡游高度 |

通用实现位于 `src/creatures/collision.js` 和 `src/creatures/rig-collision.js`。碰撞修正同时更新 Verlet 历史位置，避免将位置纠正变成下一帧的额外速度。

## 检查范围

几何回归使用真实 GLB 顶点、骨骼权重，以及与触手着色器一致的曲线、截面和颈部变形。检查墙体、台阶、池底、天花板和栈道；深渊在 `y=-18` 以下开放的空间按场景规则处理。

这些结果覆盖脚本中的确定性路线和动作，未穷举所有随机追逐路线，也未逐一采样眼球、牙齿和吸盘等附属网格。浏览器流程检查不等同于对所有怪物动画逐帧目视验收。

## 与持续移动检查的区别

本页的隔墙攻击及姿态几何检查通过，并不代表每种怪物可以沿巡逻路线持续行进。2026-09 的新增长时运动诊断发现以下仍未解决的问题：

| 怪物 | 诊断 | 当前结果 |
| --- | --- | --- |
| 追猎者 | `node tools/hunter-motion-check.mjs` | 两个窄弯分别连续停滞 32.32 秒、53.28 秒；局部回归可单独运行 `--regression` |
| 克拉肯 | 同上 | 自然下潜中途停滞；fallback 与真实 GLB 最长停滞 38.90 秒、49.43 秒 |
| 巨鲸 | `node tools/dome-motion-check.mjs --only=whale` | 120 秒内最长停滞 94.37 秒，尾部空间不足以稳定通过现有路线 |
| 蜘蛛蟹 | `node tools/dome-motion-check.mjs --only=crab` | 已有局部退让改进，仍在西侧连续停滞 27.53 秒 |
| 鮟鱇 | `node tools/dome-motion-check.mjs --only=angler` | 攻击、回位与碰撞检查通过；静止伏击是预期行为 |

Hunter 与水库怪物的完整运动诊断会因这些已知停滞返回非零。不要将它们加进 `npm run test:regression`，除非报告和断言同步更新、对应问题也确已修复。`npm run check` 目前验证局部怪物碰撞/动作回归、导航和构建；它不能替代这两项尚未通过的完整运动诊断。
