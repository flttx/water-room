# Tripothon S1 submission media — Drowned Halls

## Upload files

- `cover.png` — 1920×1080 (16:9), 2.1 MB; within the 10 MB cover limit.
- `visual-board/` — four real in-game screenshots, each 1920×1080 in English.
- `recording/tripothon-walkthrough.webm` — 1 minute 45 seconds, 1920×1080; shows the English Easy-mode route map and first-person exploration.

The cover is generated key art based on the game's first-person tiled corridor. It has no visible player model. The four visual-board images are direct captures from the game, not generated scenes.

## Tripo contribution (476 characters, bilingual)

Tripo generated six creature GLBs: image-to-model Colossus and Leviathan bodies, plus auto-rigged Crab, Angler, Whale, and Leviathan variants with swim/walk clips. I cleaned and optimized the assets in Blender, then integrated them into Three.js. Tripo powered creature-asset creation; custom code implements movement, AI, collisions, and the full game.
